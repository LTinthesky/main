# Results Folder

The scripts write their outputs here.

Typical output folders:

- `01_deseq2_RI_analysis`
- `02_concordant_gene_sets`
- `03_elastic_net_RNA_RI_score`
- `04_elastic_net_robustness`
- `05_public_scRNA_module_score`
- `06_public_xenium_spatial_score`

Generated results are not tracked by default unless they are small, deidentified source-data tables approved for sharing.
